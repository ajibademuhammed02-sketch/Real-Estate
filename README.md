🏡 LUXE Home Real Estate

A modern, responsive real estate website built with HTML, CSS, and Vanilla JavaScript, focused on clean UI/UX, smooth interactions, and a professional property-browsing experience.

✨ Features

- Modern Hero Section — A full-width property showcase designed for a premium first impression.
- Property Listings — Clean and responsive property cards for displaying available properties.
- Property Filtering — Filter properties by location, property type, and number of bedrooms.
- Property Sorting — Sort properties by price and recency.
- Property Details — Interactive property details view for individual listings.
- Wishlist/Favorites — Users can interact with property favorite controls.
- Responsive Design — Optimized for mobile, tablet, and desktop screens.
- Interactive UI — Smooth client-side interactions powered by JavaScript.

🛠️ Technologies Used

- HTML5 — Semantic page structure
- CSS3 — Responsive layouts, Flexbox, CSS Grid, custom styling, and animations
- JavaScript (Vanilla ES6+) — Filtering, sorting, modals, and interactive functionality
- Font Awesome — Icons
- Google Fonts — Typography
